Shared FLWeb assets live here.

Use this directory for reusable browser-facing media, for example:
- notification sounds
- shared UI sound effects
- common announcer clips

XTRN-specific assets should live under that XTRN in:

`assets/web/`

Examples:
- `/sbbs/mods/flweb/assets/notify.mp3`
- `/sbbs/xtrn/nba_jam/assets/web/boomshakalaka.mp3`
